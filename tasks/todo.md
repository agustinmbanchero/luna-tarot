# todo.md — plan de trabajo activo

Formato: un plan por tarea. Elementos **verificables** (se puede demostrar que pasan),
no descripciones vagas. Se marcan a medida que se completan.

## Cómo se usa

1. Antes de implementar, se escribe acá el plan con checkboxes.
2. Check-in con el usuario para validar el plan.
3. Se marcan `[x]` los elementos a medida que se completan y se demuestran.
4. Al terminar, se añade una sección **Revisión** con: qué cambió, cómo se verificó,
   qué quedó fuera y por qué.
